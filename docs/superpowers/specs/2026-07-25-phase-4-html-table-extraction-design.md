# Phase 4 HTML 表格识别与导出设计

## 目标与范围

本轮实现 Phase 4 的 4.6–4.7：识别标准 HTML 表格，正确处理 `rowspan`、`colspan` 和多级表头，并提供数据预览及 CSV、JSON、Markdown 导出。

本轮不实现项目管理与 Selector 回归验证，也不包含 CSS Grid/Flex 伪表格、Excel `.xlsx`、行列筛选、排序、编辑、跨页抓取或分页自动遍历。

## 方案选择

采用基于现有 `ElementSnapshot` 的按需纯函数解析方案。DOM 捕获层继续保持通用；只有当用户选中 `<table>` 或其内部节点时，渲染层才从当前快照定位最近的所属表格并解析数据。

该方案具有以下特点：

- 不新增目标页面执行协议，也不依赖新的 CDP 调用。
- 复用 Phase 3 的统一快照，因此同源 iframe 和 open Shadow DOM 中的表格可直接解析。
- 解析器与导出器可在 Node.js 测试环境中独立测试。
- 表格数据由当前快照派生，不在 Zustand 中长期保存，避免刷新后的陈旧状态。

未采用以下方案：

- 通过 CDP 在目标页执行表格提取脚本：会增加 IPC 和运行时脚本，并可能与当前 DOM 快照不同步。
- 捕获 DOM 时预先解析所有表格：会让通用快照模型承担表格业务，并在用户不使用表格功能时产生不必要开销。

## 模块边界与数据流

### 表格解析

新增 `src/shared/tableExtraction.ts`，负责：

- 从当前选中节点沿父链查找最近的 `<table>`。
- 只收集当前表格的直属表格区段、行和单元格，隔离嵌套表格。
- 读取单元格文本、`rowspan`、`colspan` 和表头类型。
- 将合并单元格展开为矩形逻辑网格。
- 识别多级表头并生成扁平化列名。
- 生成供预览和导出共同使用的规范化表格模型。

表格模型区分：

- 原始单元格：文本、行列跨度、是否为表头。
- 规范化矩阵：每个合并区域的值已经复制到其覆盖的逻辑位置。
- 表头路径：每一列从上到下的非重复表头片段。
- 扁平表头：使用 ` / ` 连接表头路径，例如 `Q1 / Selectors`。
- 数据记录：以唯一扁平表头为键的对象。

重复表头追加从 2 开始的稳定序号。空表头使用 `Column 1`、`Column 2` 等稳定列名，确保 JSON 对象不会发生键覆盖。

### 数据导出

新增 `src/shared/tableExport.ts`，只接收规范化表格模型并生成：

- CSV：UTF-8 文本、CRLF 换行、RFC 4180 字段转义。复制内容不含 BOM；保存的 `.csv` 文件添加 UTF-8 BOM，以改善 Excel 中文兼容性。
- JSON：两空格缩进的对象数组，键为唯一扁平表头。
- Markdown：标准 Markdown 表格，转义管道符，并将单元格内换行转换为 `<br>`。

三种格式必须共享同一份规范化数据，不允许各自重新解释合并单元格或表头。

### 文件保存

在共享 IPC 类型中增加表格导出保存请求和结果，在 Electron 主进程中使用原生保存对话框。保存逻辑：

- CSV 默认扩展名 `.csv`，JSON 为 `.json`，Markdown 为 `.md`。
- 用户取消保存返回明确的取消结果，不显示错误。
- 主进程验证格式与扩展名，不接受任意文件类型。
- 写入失败返回可展示的错误信息。

复制仍由渲染进程使用剪贴板 API 完成。

### 工作台呈现

右侧面板增加条件显示的“表格数据”折叠区：

- 选中 `<table>` 或它内部任意节点时显示。
- 选中非表格元素时隐藏。
- 显示数据行数、列数和表头层级摘要。
- 提供横向滚动、纵向虚拟化的数据网格。
- 提供 CSV、JSON、Markdown 预览标签。
- 提供复制和保存文件操作及成功、取消、失败反馈。

表格模型通过 `useMemo` 从 `domSnapshot` 和 `selectedElementId` 派生。DOM 快照变化或用户切换元素时自动重新计算，不向 Zustand 增加可失效的表格缓存。

## 解析语义

### 行与单元格收集

- 支持 `<thead>`、`<tbody>`、`<tfoot>` 以及 `<table>` 下的直属 `<tr>`。
- 行只接受直属 `<th>` 和 `<td>`，不会递归吸收嵌套表格的行。
- 区段按 DOM 顺序处理。
- 无效、缺失或小于 1 的跨度按 1 处理。

### 合并单元格

解析器维护占位网格。放置单元格时跳过已被先前 `rowspan` 占用的位置，并将值复制到 `rowspan × colspan` 覆盖的每个逻辑坐标。

最终矩阵宽度取所有逻辑行的最大宽度，短行在末尾补空字符串。该矩形矩阵是预览和全部导出格式的唯一数据来源。

### 表头识别

- 存在 `<thead>` 时，其所有行构成表头。
- 没有 `<thead>` 时，表格开头连续且全部由 `<th>` 组成的行构成表头。
- 没有可识别表头时，所有行均为数据，并生成 `Column N` 列名。
- 每一列的表头路径按从上到下顺序收集；相邻层因 `rowspan` 展开产生的重复文本只保留一次。
- 路径片段经过空白归一化后用 ` / ` 连接。

### 文本提取

- 合并连续空白并去除首尾空白。
- 单元格自身文本和非表格后代文本按 DOM 顺序组合。
- 嵌套 `<table>` 的内容不计入外层单元格文本。

## 错误与空状态

- 未选中表格时不显示表格面板。
- 空表格显示“没有可提取的数据”，不生成看似成功的空导出。
- 无法形成任何逻辑列时返回解析错误。
- 当前节点或表格在快照刷新后失效时，立即清除派生结果。
- 保存对话框取消属于正常状态。
- 剪贴板或文件写入失败显示本地化错误，不改变当前预览。

## 测试策略

### 表格解析单元测试

覆盖：

- 普通单级表头。
- `rowspan`、`colspan` 及两者混合。
- 多级表头扁平化。
- 无 `<thead>` 的前导 `<th>` 表头。
- 完全无表头时生成 `Column N`。
- 重复表头和空表头的唯一列名。
- 不规则短行补空字符串。
- 嵌套表格隔离。
- 从 `<table>`、`<th>`、`<td>` 和单元格内部元素定位最近表格。
- 带 frame/shadow 上下文的表格快照。

### 导出单元测试

覆盖：

- CSV 中逗号、引号、换行和 Unicode。
- JSON 列名唯一性、值映射和格式化。
- Markdown 管道符和换行。
- 三种格式的数据行和列顺序一致。

### IPC 与呈现辅助测试

覆盖：

- 保存格式到扩展名和文件过滤器的映射。
- CSV 文件 BOM，JSON/Markdown 文件不加 BOM。
- 用户取消和写入失败的结果。
- 表格面板显示条件、摘要和导出状态的纯呈现逻辑。

## 验收标准

使用内置 `public/test-pages/table.html` 验收：

1. 选中表格、表头或数据单元格均显示同一个表格预览。
2. 解析结果为 5 列，表头依次为：
   - `Team`
   - `Q1 / Selectors`
   - `Q1 / Pass rate`
   - `Q2 / Selectors`
   - `Q2 / Pass rate`
3. `Identity` 行的 `Migration` 同时出现在两个 Q1 逻辑列。
4. CSV、JSON、Markdown 预览与网格数据一致。
5. 复制内容可直接使用，保存操作生成正确扩展名和编码的文件。
6. `npm test`、`npm run typecheck` 和 `npm run build` 全部通过。
